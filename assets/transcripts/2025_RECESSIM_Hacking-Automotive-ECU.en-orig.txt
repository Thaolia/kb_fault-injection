## Méthodologie transférable au projet

[08:54–09:25] "Broom method" : câble de cuivre dénudé balayé en traînée sur la carte pour localiser
  des pins inconnus par détection sonore de continuité, avant de zoomer sur la zone.
[07:03–08:00] Dessoudage BGA au heat gun pratiqué sur une carte de sacrifice (seconde carte morte
  obtenue exprès) plutôt que de risquer l'unique carte cible.
[24:53–27:15] ★ Détection "no-code" d'un glitch réussi : observation à l'oscilloscope d'une
  dérive/interruption du pin clock-out du MCU, sans écrire aucun firmware de test. Découverte en
  tentant de synchroniser le ChipWhisperer sur ce même signal.
[12:12–13:16] Entrée en mode BAM : nécessite un pin "boot config" ET un registre "reset config" —
  ce dernier absent du papier d'O'Flynn selon l'orateur (chiffres de comptage non recoupés).
[08:14–08:38] Sur cette génération, le pin de boot externe n'est pas désactivable ; les générations
  plus récentes permettraient de le désactiver (contre-mesure) — affirmation orale non recoupée,
  mais cohérente avec ce que documente le papier O'Flynn `[corpus]` (p. 3, p. 16).
[41:24–49:00] ★ Contournement du flooding CAN : un contrôleur CAN retransmet en boucle si aucun ACK
  n'est reçu, ce qui casse tout glitch précis sur un message unique → passage par un mode "one-shot"
  d'un contrôleur CAN dédié (les adaptateurs USB-CAN du commerce ne le supportaient pas).
[1:08:15–1:09:50] ★ Contrainte ECC mémoire : le code injecté ne s'exécute pas si toute la RAM/pile
  utilisée n'est pas initialisée au préalable → contourné en envoyant un bloc de zéros avant le code.
[1:11:05–1:14:00] Séquence matérielle finale : ChipWhisperer pilote reset + surveille l'horloge ;
  un Arduino envoie le message 1 (mot de passe) ; un décodeur CAN séparé lit ce message en direct
  sur le fil pour caler le déclenchement du pulse EMFI ; puis message 2 (adresse + taille).
[1:15:02–1:16:04] Exfiltration via IDs d'arbitration CAN dédiés : 100/101 = code BAM, 200/201 = zone
  "shadow" contenant le mot de passe, 300/301 = flash complète.
[59:59–1:00:33] Astuce de sourcing : les revendeurs d'outils de chip-tuning publient des photos de
  cartes ouvertes avec pins CAN/boot déjà identifiés — évite la broom method.
